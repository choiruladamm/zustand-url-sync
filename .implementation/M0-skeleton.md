# M0 — Skeleton

**Goal:** a repository that can build, test, lint, measure and publish nothing. Every gate that later phases rely on exists and passes on an empty `src/`.

**Size:** S · **Depends on:** nothing · **Next:** M1

Read first: `CLAUDE.md`, `.claude/rules/versioning.md`, `PRD.md` §8.

---

## Why this phase exists

Every gate in `.claude/rules/testing.md` is cheap to add now and expensive to retrofit. A size budget added after the code is written gets set to whatever the code happens to weigh. An API snapshot added at 1.0 freezes accidents. Build the scaffolding while there is nothing to protect, so the first real commit is already under it.

Ship **no library code** in this phase. Placeholder `index.ts` files that export nothing are correct.

## Tasks

### 1. Git + package

`git init`, default branch `main`. `.gitignore`: `node_modules`, `dist`, `coverage`, `.turbo`, `*.tsbuildinfo`, `test-results`, `playwright-report`.

`package.json`:
- `name: "zustand-url-sync"`, `version: "0.0.0"`, `license: "MIT"`, `type: "module"`, `sideEffects: false`
- `"dependencies": {}` — and it stays that way
- `peerDependencies`: `zustand: "^5"`, `react: "^18 || ^19"`; both in `peerDependenciesMeta` as optional except zustand
- `files: ["dist"]`
- no `main`/`module`/`types` fields — tsdown generates `exports` (PRD §8)

`LICENSE`: MIT, holder `Choirul Adam`.

**Done when:** `pnpm install` succeeds and `git log` has one commit.

### 2. TypeScript

`tsconfig.json`: `strict: true`, plus `noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`, `noImplicitOverride`, `verbatimModuleSyntax`. `target: "ES2020"`, `moduleResolution: "bundler"`, `noEmit: true`.

`noUncheckedIndexedAccess` matters here specifically: this library indexes `Record<string, ParamSpec>` by user-supplied keys constantly, and the flag is what forces those lookups to be handled rather than assumed.

**Done when:** `pnpm typecheck` (`tsc --noEmit`) passes.

Each contains `export {}` for now.

### 4. Build — tsdown

`tsdown.config.ts` exactly as PRD §8, with `entry` covering `src/index.ts`, `src/{codecs,react,server}/index.ts`, `src/adapters/*/index.ts`.

Note `storage/`, `core/` and `middleware/` are **not** entrypoints — they are internal, reachable only through `.`.

**Done when:** `pnpm build` emits `dist/` with `.js`, `.cjs` and `.d.ts` per entry, and the generated `exports` map in `package.json` lists exactly the intended entrypoints.

### 5. Lint + format — Biome

`biome.json`: formatter on, linter on with `recommended`, plus `noExplicitAny: "error"` and `useImportType: "error"`. Single quotes, no semicolons, 100 col — pick once, never discuss again (`.claude/rules/conventions.md`).

**Done when:** `pnpm lint` and `pnpm format:check` pass.

### 6. Layer boundaries — dependency-cruiser

`.dependency-cruiser.cjs` encoding the table in `.claude/rules/architecture.md`:

- `src/core/**` may not import anything outside `src/core/**`
- `src/codecs/**` may import only `src/core/**`
- `src/adapters/**` may import only `src/core/**`
- `src/storage/**` may import `src/core/**`, `src/codecs/**`
- no circular dependencies anywhere
- `src/core/**` may not import `react` or `zustand`

**Done when:** `pnpm lint:arch` passes, and passes for the right reason — temporarily add a forbidden import, confirm it fails, remove it. An unverified boundary rule is worse than none, because it is trusted.

### 7. Test harness — Vitest

`vitest.config.ts`: `environment: 'happy-dom'`, globals off (import explicitly), coverage via v8 gated on `src/core/**` at 90%.

Add `test/types/` with `tsd` or `expect-type` wired to `pnpm test:types`. Prove the harness works: write one negative type test that must fail to compile, confirm the runner catches it, then replace it with a trivial passing one.

**Done when:** `pnpm test` runs (zero tests is fine) and `pnpm test:types` runs.

### 8. Frozen artifacts

The three from `.claude/rules/versioning.md`. All three exist now, empty, and are already gated.

- `api/public-api.md` — generated by `pnpm api:update` from the built `.d.ts`
- `api/wire-format.md` — generated from the codec registry; empty table until M1
- `.size-limit.json` — one entry per entrypoint. Set budgets to the PRD targets (core 3 kB, adapters 0.6 kB), not to current size

`pnpm api:check` regenerates into a temp file and diffs; non-zero exit on drift.

**Done when:** `pnpm api:check` and `pnpm size` pass against empty output.

### 9. Changesets

`pnpm changeset init`. Add a CI step failing any PR that touches `src/` without a changeset.

### 10. CI

`.github/workflows/ci.yml`, matrix Node 22 and 24, one job:

```
install → typecheck → lint → lint:arch → test → test:types → build → api:check → size → publint → attw
```

Order matters: cheap and specific first. A typo should fail in 20 seconds, not after a full build.

Add a separate `release.yml` using the changesets action, gated on CI. Leave it disabled (`if: false`) until M6 — the workflow is reviewed now, armed later.

## Traps

- **Don't set size budgets from measurement.** There is nothing to measure. Use the PRD's targets; if M1 blows through them that is information, and silently raising the budget is how a 3 kB library becomes 12 kB.
- **Don't add `main`/`module`/`types` "just in case".** They conflict with the generated `exports` map and `publint` will flag it — but only after they've already confused someone.
- **Don't skip verifying the boundary rules.** A rule you never saw fail is a rule you have no evidence works.
- **`type: "module"` + `.cjs` output** is the combination `attw` exists to police. If it's wrong, it's wrong now, and it's a five-minute fix now.

### Deviations from the plan, and why

1. **TypeScript pinned to 5.9.3, not the 7.0.2 that is `latest`.** TS 7 is the Go port; tsdown's
   `dts: true` runs `rolldown-plugin-dts` against the TS compiler API, which TS 7 exposes only as a
   shim. Not a fight worth having during M0. Revisit when tsdown states TS 7 support.
2. **`exports: { legacy: false }` in `tsdown.config.ts`.** tsdown 0.22.14 generates top-level
   `main`/`module`/`types` **by default**, which is exactly the trap this phase's list warns about.
   The flag is what keeps them out. PRD §8 shows `exports: true` — treat that as shorthand.
3. **`attw` runs with `--profile node16`.** Without legacy fields, node10 resolution fails by
   design. PRD §8 already specifies the node16 profile; the script now matches it.
4. **No `types` condition in the generated `exports` map.** tsdown relies on TypeScript resolving
   `dist/x.js` → `dist/x.d.ts`. attw node16 confirms this works from both CJS and ESM. The API
   snapshot script derives the `.d.ts` path the same way — see `scripts/api-snapshot.mjs`.
5. **`engines.node: ">=20"` added.** publint flagged its absence. Matches PRD §8's support policy.
6. **`vitest` runs with `passWithNoTests: true`.** M0 ships no code and no tests. **Flip this to
   `false` in M1** — it is the difference between "no tests" and "tests silently not collected".
7. **`no-orphans` excludes `index.ts`.** Every barrel and build entrypoint is an orphan by design.
8. **`not-to-dev-dep` excludes `npm-peer`.** zustand and react are devDependencies *and* peers.
   Without the exclusion the rule fires the moment M2 imports zustand. **M4 must add each router to
   `peerDependencies` + `peerDependenciesMeta.optional` before its adapter imports it** — otherwise
   `pnpm lint:arch` fails, correctly.
9. **Coverage is configured but not in the CI job list.** Thresholds (90% on `src/core/**`) are set
   in `vitest.config.ts`; there is nothing to cover yet. **M1 adds `pnpm test -- --coverage` to CI.**
10. **Two artifacts, not three, are generated by `pnpm api:update`.** `.size-limit.json` is
    hand-maintained — it is a budget, not a snapshot.

### Verifications that were actually run (not assumed)

- **Layer rules fail for the right reason.** Four deliberate violations added and confirmed to
  error: `core → zustand`, `codecs → middleware`, `adapters → codecs`, `middleware → react`
  (exit 5). Then confirmed `middleware → zustand` stays clean while `middleware → happy-dom` errors.
- **Negative-type harness catches both failure modes.** An `@ts-expect-error` that stops erroring
  fails with TS2578; a wrong `expectTypeOf` fails with TS2344. `test/types/harness.test-d.ts` keeps
  both live — replace it with real cases in M2, don't delete it.

### Empty-build floor

Every entrypoint: **13 B gzip** (ESM). This is the floor every later size measurement sits on.

Budgets set from PRD targets, not measurement: `.` 3 kB · `./codecs` 1.5 kB · `./react` 1 kB ·
`./server` 700 B · each adapter 600 B. The codecs/react/server numbers are not in the PRD — they
were chosen here and are the ones most likely to need a deliberate, argued change.

### Known gotcha, local only

`pnpm lint` run through this machine's `rtk` shell hook prints
`[warn] Linter process terminated abnormally (possibly out of memory)` and swallows the real output.
Biome is fine. Use `rtk proxy "pnpm lint"` or `./node_modules/.bin/biome lint .` when checking
locally. CI is unaffected.
